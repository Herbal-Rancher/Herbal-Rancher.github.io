## Overview

This milestone assessment examines how the physical infrastructure, switching, routing, wireless access, and centralized services work together as a network system. It follows connectivity from the media and devices through LANs, WANs, VPNs, and cloud resources, while considering security, reliability, performance, scalability, and the practices needed to operate the network over time.

---

## Assessment Focus

- Network systems and their effect on business continuity and security
- Copper and fiber media, transceivers, wireless, PoE, UPSs, and physical network spaces
- VLAN segmentation, access ports, and IEEE 802.1Q trunks
- RSTP and LACP for Layer 2 resilience
- Port security and IEEE 802.1X access control
- Inter-VLAN routing, routing tables, and WAN connectivity
- RIP, OSPF, EIGRP, and BGP routing characteristics
- WLAN coverage, corporate and guest access, and RADIUS authentication
- Remote-access and site-to-site VPNs, and cloud networking
- Common network ports, protocols, and centralized services
- Layered security controls across network infrastructure and services
- Validation, monitoring, systematic troubleshooting, and performance baselines
- Firmware updates, configuration backups, change management, and network documentation

## Reflection

This milestone assessment strengthened my understanding of a network as a system whose parts must work together. Physical media and power support the devices; switching and VLANs organize local traffic; routing connects separate networks; and wireless, WAN, VPN, and cloud technologies extend access to users and services. Studying how security and redundancy apply across those layers also reinforced why a network must be validated, monitored, maintained, and documented as it changes.
