## Overview

This summative assessment demonstrates hands-on Ethernet network connectivity by identifying and connecting appropriate copper cables and connectors in a simulated network environment. The lab focuses on recognizing physical network connection requirements and selecting the appropriate Ethernet cabling to establish connectivity between network devices.

The completed lab provides practical evidence of my understanding of enterprise transmission media and the physical infrastructure used to support Ethernet networks.

---

## Assessment Focus

* Ethernet network connectivity
* Copper network cabling
* Ethernet cable and connector identification
* Selection of appropriate physical connections
* Connecting network devices using copper media
* Transmission media in enterprise networks
* Physical Layer network infrastructure
* Reliable endpoint-to-network connectivity

---

## Competencies Demonstrated

* **IT532:OS6.1 — Configure switching technologies and features**
  * Connect Ethernet network devices to switching infrastructure using appropriate physical connections.

* **IT532:OS6.2 — Explain common networking ports, protocols, services, and traffic types**
  * Apply Ethernet connectivity concepts when identifying network interfaces and establishing device connections.

* **IT532:OS6.3 — Compare and contrast transmission media and transceivers**
  * Identify and select copper Ethernet cabling and connectors according to the requirements of the network connection.

* **IT532:OS6.4 — Compare and contrast network topologies, architectures, and types**
  * Demonstrate how Ethernet physical connections support devices within a local network environment.

## Reflection

This summative assessment reinforced the importance of the Physical Layer as the foundation of network communication. Completing the Ethernet connectivity lab gave me practical experience identifying copper cabling and connectors and selecting the appropriate physical connections between network devices.

The activity also strengthened the connection between physical network infrastructure and the larger enterprise environment. Even when switching, routing, security, and network services are configured correctly, reliable communication still depends on selecting and connecting the appropriate transmission media.
