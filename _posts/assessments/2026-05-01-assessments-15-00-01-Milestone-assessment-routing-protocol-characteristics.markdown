## Overview

This milestone assessment examines how routers direct IP traffic between
networks, how routing information is learned and selected, how
segmentation separates network traffic, and how tracing tools help
identify connectivity and routing problems. It compares static and
dynamic routing, examines RIP, OSPF, EIGRP, and BGP, and connects
routing-table decisions with practical network troubleshooting.

---

## Assessment Focus

* Layer 3 routing and packet forwarding
* Static routing
* Dynamic routing
* Default routes
* Distance-vector, link-state, advanced distance-vector, and path-vector routing
* RIP hop-count routing
* OSPF cost and Shortest Path First
* EIGRP composite metrics and DUAL
* BGP path attributes and interdomain routing
* Routing tables and forwarding decisions
* Longest prefix match
* Administrative distance
* Routing protocol metrics
* VLAN and subnet segmentation
* Inter-VLAN and inter-subnet routing
* Security benefits of network segmentation
* Ping connectivity testing
* Tracert and traceroute path analysis
* Packet analysis with Wireshark
* Host, port, and service discovery with Nmap
* Systematic routing troubleshooting

## Reflection

This milestone assessment strengthened my understanding of routing as
the process that connects separate networks and determines how packets
reach their destinations. Comparing static and dynamic routing and
studying RIP, OSPF, EIGRP, and BGP helped me understand how different
routing technologies learn and select paths. Examining longest prefix
match, administrative distance, and metrics clarified how routing-table
decisions are made, while segmentation and tracing exercises connected
routing concepts to security, performance, management, and systematic
troubleshooting.
