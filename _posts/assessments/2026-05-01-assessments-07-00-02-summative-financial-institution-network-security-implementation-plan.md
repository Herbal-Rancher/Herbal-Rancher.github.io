## Overview

A scenario-based security implementation plan for a financial institution facing unauthorized access attempts, malware, and phishing campaigns.

---

## Assessment Focus

* Risk-based security planning for a financial institution
* Defense in depth and sensitive financial data protection
* Firewalls and intrusion detection/prevention
* Identity, authentication, and privileged access
* Malware and phishing defenses
* Monitoring, incident response, and recovery

## Reflection

Developing this plan strengthened my ability to translate network security principles into practical organizational safeguards. It emphasized prioritizing controls based on business risk and verifying security measures rather than relying on assumptions.
