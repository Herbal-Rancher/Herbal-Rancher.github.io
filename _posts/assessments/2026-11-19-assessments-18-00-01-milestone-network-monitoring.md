## Overview

A network monitoring scenario for a 250-employee professional-services company, comparing monitoring technologies, management access methods, and operational challenges.

---

## Assessment Focus

* SNMP monitoring and interface statistics
* Syslog event analysis
* ICMP reachability and latency
* NetFlow/IPFIX and packet analysis
* SSH, console, HTTPS, SNMPv3, and API management
* Alert fatigue, data overload, privacy, and monitoring security

## Reflection

This assessment strengthened my understanding that useful monitoring is about actionable evidence, not just collecting more data. I compared secure management methods and considered how baselines, meaningful alerts, and privacy safeguards support proactive network operations.
