## Overview

An enterprise network administration scenario focused on troubleshooting email, internet connectivity, slow file transfers, and performance issues.

---

## Assessment Focus

* Core administrator responsibilities and essential skills
* CompTIA six-step troubleshooting methodology
* Email service diagnostics and DNS resolution
* Internet connectivity, routing, and NAT
* Network congestion, interface errors, and server performance
* SNMP, Syslog, SSH, and preventive maintenance
