## Overview

A Cisco Packet Tracer security lab configuring router and switch access controls, local authentication, SSH, login restrictions, and administrative safeguards.

---

## Assessment Focus

* Router and switch management addressing
* Privileged access and password security
* Local user authentication
* SSH remote access and VTY line configuration
* Login blocking and session timeouts
* Disabling unused switch ports and verifying saved configurations
