## Overview

This summative assessment applies IPv4 addressing and subnetting in a
hands-on network scenario. The activity requires designing a subnetting
scheme from a 192.168.0.0/24 network, configuring router interfaces,
switches, and host devices, and testing connectivity to verify that the
completed addressing plan operates correctly.

---

## Assessment Focus

* IPv4 subnetting
* CIDR prefix notation
* Subnet mask calculation
* Network and host portions
* Borrowing host bits for subnetting
* Subnet and host capacity
* Network, host-range, and broadcast addresses
* Router interface addressing
* Switch management addressing
* Default gateway configuration
* Device configuration
* Ping connectivity testing
* Network troubleshooting

## Reflection

This summative assessment gave me practical experience turning
subnetting calculations into a working network configuration. Designing
four /26 subnets from a /24 network reinforced how borrowed bits affect
subnet and host capacity, while configuring routers, switches, and PCs
helped connect CIDR notation and subnet masks to actual device
addressing. Testing connectivity with ping then provided a way to
validate the design and troubleshoot configuration errors.
