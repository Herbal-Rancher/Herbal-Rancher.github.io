## Overview

This summative assessment applies routing, network segmentation, network tracing, and secure device-management concepts through Packet Tracer Lab 21 — Secure Network Devices. The activity documents the configuration and hardening of a router and switch, secure remote management with SSH, management addressing, and connectivity testing across two IPv4 LANs.

---

## Assessment Focus

* Document network addressing and default gateways
* Configure and harden router and switch devices
* Configure secure console and VTY access
* Configure encrypted privileged access and local authentication
* Enable SSH version 2 for secure remote management
* Restrict VTY access to SSH
* Configure login protection against repeated failed attempts
* Administratively disable unused switch ports
* Configure a switch management SVI and default gateway
* Save and verify device configurations
* Test reachability to the switch management interface
* Apply secure network-device management practices

## Reflection

I chose Secure Network Devices because the lab provided detailed practice securing and managing routers and switches. One of the most valuable challenges was having to identify and verify the correct commands and security practices rather than simply following every configuration step without investigation. This strengthened my familiarity with Cisco IOS commands, secure device management, SSH configuration, authentication, password protection, management addressing, and connectivity verification.

Completing the lab also reinforced how routing, segmentation, security, and network tracing work together in practice. Configuring the router and switch, securing management access, assigning the switch management interface and default gateway, and verifying connectivity with ping helped connect device configuration to the larger goal of maintaining secure and reachable network infrastructure.
