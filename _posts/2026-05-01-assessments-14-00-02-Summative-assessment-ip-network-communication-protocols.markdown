## Overview

This summative assessment applies network communication protocols in a
hands-on Packet Tracer scenario by configuring DHCP services on a
wireless router and verifying dynamic IPv4 addressing and connectivity.
The activity connects protocol concepts to practical client
configuration, address assignment, default-gateway operation, and
network testing.

---

## Assessment Focus

* DHCP client-server communication
* Dynamic IPv4 address assignment
* Wireless router IPv4 configuration
* DHCP server configuration
* DHCP address-pool modification
* Default gateway identification
* Client IP configuration
* Address renewal
* Verification with ipconfig
* ICMP connectivity testing with ping
* Communication between network devices
* Network troubleshooting and validation

## Reflection

This summative assessment gave me practical experience applying DHCP and
IPv4 communication concepts in a working network. Changing the wireless
router address and DHCP pool demonstrated how client addressing depends
on the network configuration provided by the DHCP server. Renewing
client addresses, examining the resulting configuration with ipconfig,
and testing communication with ping reinforced the relationship between
addressing, the default gateway, DHCP services, and successful
end-to-end connectivity.
