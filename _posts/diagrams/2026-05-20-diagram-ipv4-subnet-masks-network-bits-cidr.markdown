## Overview

This study diagram explains how subnet masks, network bits, host bits, and CIDR notation work together to divide IPv4 address space into networks and hosts.

<!--more-->

The diagram combines these closely related concepts into a single visual reference for understanding subnet boundaries, common CIDR prefixes, usable host ranges, and basic IPv4 subnet calculations.
