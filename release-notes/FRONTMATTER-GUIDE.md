# Post front matter

Use `portfolio: network-plus` and `hr_theme: network` for networking; `portfolio: security-plus` and `hr_theme: security` for cybersecurity. Include `layout: post`, `title`, `category`, `category_display`, `subcategory`, `subcategory_display`, `topics`, `tools`, and a unique permalink. Security category keys are defined in security-portfolio/index.markdown. Existing untagged network posts remain visible.
